# XFEL 单脉冲材料损伤阈值统计程序

本目录是把原来的 `xfel_damage_analyzer.py`、`GMD_reader.py` / `transfer_select.py` 和 `阈值计算.py` 合并后的四步骤 Windows 桌面程序。

双击 `run_xfel_app.bat` 启动。程序优先使用本机 Python 3.11；首次运行缺少依赖时会按 `requirements.txt` 自动安装。也可先双击 `install_dependencies.bat`。若启动失败，窗口会停留并把完整错误写入 `xfel_startup_error.log`，不会再直接闪退。

## 下载与安装

运行环境为 Windows + Python 3.11（需安装 Python Launcher，使 `py -3.11` 可用）。下载本仓库 ZIP 后解压，或执行：

```powershell
git clone https://github.com/Leonids312/XFEL_Eth.git
cd XFEL_Eth
py -3.11 -m pip install -r requirements.txt
py -3.11 xfel_damage_threshold_app.py
```

公开仓库仅包含集成程序、测试和使用说明，不包含原始 HDF5/徕卡图像、实验项目存档、计算输出、本机路径配置，以及针对特定实验数据的一次性处理脚本。使用时请自行选择本地数据；保存项目并不会把其引用的原始数据一同打包。

## 推荐操作顺序

1. **统计损伤面积**
   - 选择徕卡图像文件夹。支持 `atten0,3_L1-2_R1-5.tif` 和 `atten1.5_no_11-20.tif` 两类名称。
   - 分割模式可选“正入射”或“掠入射”。掠入射模式按 `atten1.5_no_11-20.tif` 一类名称读取：`atten` 后的第一个数是衰减倍数，`no_` 后的范围是序号；图像按序号数量纵向切成横向条带。可为每个衰减倍数分别设置序号从上到下或从下到上，方向与模式随项目保存。
   - 调整灰度、面积、滤波和闭运算参数，处理当前图或全部图。
   - 自动结果可改为无损伤、图像截断（不统计）、点击候选轮廓或手动画轮廓；滚轮缩放、右键拖动平移。交互预览只裁剪和缩放当前屏幕可见区域，连续事件按帧合并；拖动时直接移动现有画布，停止后补充高质量渲染，因此不会因原始多百万像素图或高倍率放大而生成超大临时位图。面积与轮廓计算始终使用原始分辨率数据。
   - “显示样式”分页可分别设置自动/手动/选中轮廓、注释、比例尺和网格的颜色、线宽及注释字号；这些设置也用于第 4 步的点位详情图。注释由界面矢量文字直接绘制，缩放时保持清晰。
   - 必须按实验设置“全局 R 列号增长方向”，并在左侧逐衰减组、逐行设置实际打点方向。序号采用原程序的蛇形映射逻辑；修改方向后第 3 步的面积对应会立即重算。
   - 比例尺换算后使用 µm²，否则使用 px²。每次修改会自动同步到第 3 步，也可单独导出 Excel。
   - “导入旧面积存档”可读取原面积程序的 JSON 项目。

2. **GMD–PD 标定与缓存**
   - “从项目读取第2步数据”可选择另一个集成项目，仅读取其第2步的拟合缓存、独立拟合范围、文件路径、Pprime、标准化斜率、PD背底及气体衰减分析数据；可选择追加去重或完整替换。当前项目第1、3、4步数据和已应用的命名常数不会被自动改写，该文件选择位置单独记忆。
   - 可选择一个标定文件夹并向下递归遍历全部 `.hdf5/.h5`，也可通过“单个 HDF5”路径只添加并拟合一个文件；两类文件选择分别记忆上次位置。每个文件会在完成 GMD–PD 拟合的同时读取物理 PD（`-mso:Area`）最低值，并一起进入拟合缓存区；缓存新增“PD 最低值 (V·s)”列，批处理结果还会给出全局最低值及来源。
   - “文件目录”显示源文件及其上两级目录，旁边的“文件修改时间”来自 HDF5 文件属性。缓存默认按目录自然升序排列，路径中的连续数字按数值比较，例如同日期下 `run9` 排在 `run10` 前面。也可点击其他列改为相应列的升序/降序，并可多选后一次删除；固定总列宽使底部横向滚动条可完整查看全部列。
   - 每份缓存及其每个偏移都可单独填写 X/Y 拟合范围。“应用拟合范围”会用范围内数据重新拟合并覆盖该缓存的参数，范围外点保留为同色系浅色点且不占用图注；应用时保留当前图的 X/Y 查看范围，不自动缩放坐标轴。拟合直线延伸到当前坐标轴边框附近，但在端点与边框之间保留轻微间隙，不会终止在参与拟合的数据点处。
   - 缓存区上方提供两个独立分析窗口。“气体衰减常数测定”可粘贴 P–斜率两列数据，按 `ln(r)=ln(A)+kP` 拟合并绘制原尺度指数曲线，给出 `k`、`A`、`sigma_k`（1σ）和拟合优度；可将 `k` 与 `sigk` 一键应用到第 3 步命名常数。
   - 双击缓存表的 `Pprime (Torr)` 单元格可填写标定气压；应用缓存到公式时按 `Bfit/exp(k·Pprime)` 计算并写入单一命名常数 `normalized_slope`。“标准化斜率统计”在独立窗口中计算全部有效缓存并绘制直方图。GMD–PD 直线仍采用自由截距拟合，但该截距只用于拟合诊断，不参与第 3 步 PD 计算。
   - 当前模型不考虑 PD 背底，也不考虑 GMD 背底；因此不再提供 PD 背底应用入口，旧项目中的 `intercept`、`sigPDBackground`、`IBG` 和 `sigBG` 仅作为兼容字段保留且不参与默认公式。
   - 缓存保留时间、全部尝试偏移、各偏移拟合参数、独立拟合范围和散点/拟合数据，并随项目文件保存。

3. **提取并对应单脉冲能量**
   - 每个衰减倍数都有独立七列表格：序号、GMD、PD、单脉冲能量、损伤面积、能量相对误差、面积相对误差。
   - 选择衰减组和序号范围，再选打损伤时的 HDF5。程序以相机时间戳的最近 GMD 索引为基准扫描偏移，按 `0.5×Pearson[ln(GMD),面积] + 0.5×Spearman[GMD,面积]` 最大值选择方案。位置数、快门数或 `shot_number` 与范围不一致时会停止并明确报错。
   - GMD 匹配成功后会立即按依赖顺序自动计算所选范围的 PD、单脉冲能量和两列相对误差。自动模式按损伤 HDF5 修改时间采用最近且参数完整的第 2 步缓存，并同时读取该缓存的 `normalized_slope`、`sig_normalized_slope` 和 `Pprime`；命名常数模式则完全采用命名常数中的这三项。界面会显示缓存来源、修改时间差和实际参数，并写入对齐日志。
   - 表格带横纵网格线；可用鼠标拖选任意矩阵后 `Ctrl+C`，也可从 Excel/Origin 复制矩阵后用 `Ctrl+V` 自动填充。序号列可复制但不可编辑或被粘贴覆盖。
   - 可新增衰减组，也可删除当前衰减组。整列公式支持以下写法：
     - 命名列：`=normalized_slope*exp(k*P)*gmd`
     - Origin：`=normalized_slope*exp(k*P)*col(B)`
     - Excel 行引用：`=normalized_slope*exp(k*P)*B2`
   - 列字母：A=序号，B=GMD，C=PD，D=能量，E=面积，F=能量相对误差，G=面积相对误差。

默认 PD 与能量公式来自现有工作簿：

```text
PD = normalized_slope*exp(k*P)*GMD
E(nJ) = PD/load_resistance/responsivity*(12398.419843/wavelength_A)*1e9
sigma_E/E = sqrt(gmd_rel_err^2 + (sig_normalized_slope/normalized_slope)^2 + ((P-Pprime)*sigk)^2 + (sigeta/eta)^2)
```

所有实验常数均可在“命名常数”窗口修改并保存。气压 `P` 可逐衰减组设置，避免把“衰减倍数”误当作气压。

4. **绘图与拟合阈值**
   - 总图使用 `S = a·ln(E_pulse)+b` 拟合，阈值为 `E_th=exp(-b/a)`。程序分别把第 3 步的能量相对误差（X 误差棒）、面积相对误差（Y 误差棒）及拟合参数协方差传播到阈值，并按 `σ_total=sqrt(σ_X²+σ_Y²+σ_fit²)` 输出 `E_th ± σ_total`；结果区同时列出三项误差分量。误差棒的显示开关只影响图形外观，不影响总误差计算。
   - 每个衰减倍数另外生成一张无误差棒、无拟合线的散点图。
   - 可自定义标题、坐标标题/范围/尺度、组颜色、点形、点大小、拟合线和网格等；“显示拟合直线”可单独隐藏/恢复阈值拟合线及其图例方程，不影响阈值计算。“坐标轴、标题字号与刻度”窗口可分别设置图标题、X/Y 标题、X/Y 刻度及图例字号，并可配置线性/对数尺度、主刻度间隔、次刻度分段、普通/科学计数格式、刻度旋转与方向、上下左右刻度和标签、边框、主/次网格等。
   - 可设置保存 DPI（50–1200）；左上角 Matplotlib 工具栏的“Configure subplots”可手动调节上下左右边距和子图间距。
   - 每次“绘图并拟合”都会把总图加入右侧会话缩略图缓存，新图按生成顺序添加在下方；点击缩略图可在左侧恢复，并同步恢复该次拟合的 `阈值 ± 总误差` 与误差分量。图例、缩略图和状态栏也显示阈值总误差。单衰减倍数散点图不单独进入缓存，但切换总图缓存时会同步重建该次数据对应的各衰减倍数散点图分页入口。关闭程序或打开其他项目后缓存自动清空。
   - 拟合筛选支持按衰减倍数多选，并可与能量/面积范围筛选及 Sigma 剔除叠加。未选衰减组和其他被排除的点仍保留在总图中，以很浅的原组颜色显示；只有正常颜色的点参与拟合。所有衰减组都会在图注中保留组名，但图注不额外标记哪些点未参与拟合，同一组也不会产生重复图注；衰减筛选设置随项目保存。
   - “应用图形设置到当前预览”只修改当前图及对应缩略图，不会重新拟合或增加一条缓存记录。
   - 总图画布初始长宽为旧版的 1.5 倍，并在页面内自动适配；首次生成即使用最终尺寸，切换缓存时不再短暂显示小图。鼠标滚轮不改变画布或 X/Y 坐标范围。每张缓存分别保存原始视角和最后查看视角，切换回来后工具栏的“Reset original view”仍可恢复该图的初始坐标范围。右键单击散点可查看该点全部数据和其所在的完整徕卡图；程序按需载入原图并实时绘制全部轮廓、网格和注释，以第 1 步设置的高亮颜色框出目标点，不为每个点生成预览缓存。也可把点移入回收站，回收站支持选中还原或全部还原。
   - 第 2、4 步的图形预览会在页面内居中自适应并限制最大尺寸，避免小屏或分栏状态下被边框遮挡。

## 项目与配置

“保存项目”生成 `*.xfel.json`，包含面积轮廓、标定缓存、能量表、公式、常数、HDF5 偏移记录、绘图设置和回收站。第 4 步右侧缩略图属于临时会话缓存，不写入项目。程序目录下的 `.xfel_integrated_config.json` 仅记录窗口大小及最近项目路径。

程序目录下的 `.xfel_dialog_paths.json` 按用途分别记录每个文件对话框的上次目录；标定文件夹、单个标定 HDF5、损伤 HDF5、旧面积存档、图像文件夹、两类 Excel、项目打开/保存、标定图和阈值图互不覆盖。

## 文件说明

- `xfel_damage_threshold_app.py`：主程序、四步骤导航和项目读写。
- `area_page.py`：徕卡图像识别、手动轮廓和面积同步。
- `calibration_page.py`：GMD–PD 批量拟合、同步 PD 最低值读取和拟合缓存管理。
- `energy_page.py`：时间戳匹配、矩阵表格、公式和 Excel 导出。
- `threshold_page.py`：阈值拟合、交互绘图、点详情和回收站。
- `remembering_toolbar.py`：带独立保存目录记忆的 Matplotlib 工具栏。
- `xfel_core.py`：共享数据模型、安全公式解释器和数值算法。
- `test_xfel_core.py`：公式、文件名、HDF5 偏移和阈值算法回归测试。

运行测试：双击 `run_tests.bat`，或执行 `py -3.11 -m unittest -v test_xfel_core.py`。
